# இயல் 9 — அன்பென்னும் அறனே | ஒருமதிப்பெண் விடைகள்

| 1. “இமயத்துக் கோடு உயர்ந்தன்ன” என்ற அடியில் “கோடு” என்பதன் பொருள் என்ன? | ஆ) மலையுச்சி | ANSWER_CONFIRMED |
| 2. தமிழ்ப் புலவரைப் போலவே உரோமச் சிந்தனையாளர் கொண்ட கொள்கை எது? | ஈ) ஒன்றே உலகம் | ANSWER_CONFIRMED |
| 3. வண்ணதாசனுக்குச் சாகித்திய அகாதெமி விருது பெற்றுத் தந்த நூல் எது? | அ) ஒரு சிறு இசை | ANSWER_CONFIRMED |
| 4. யா மரம் என்பது எந்த நிலத்தில் வளரும்? | இ) பாலை | ANSWER_CONFIRMED |
| 5. “கேடில் விழுச் செல்வம் கல்வி ஒருவற்கு / மாடல்ல மற்றை யவை” என்ற குறளில் பயின்று வந்துள்ள அணி எது? | இ) சொற்பொருள் பின்வருநிலையணி | REVIEW_REQUIRED |
